# Search

ECHO search is local, weighted text matching. It has no backend, no AI APIs, no hosted model, no embedding service, and no external data service.

## Search Panel

Open search from the left sidebar / search panel area. The panel:

- debounces queries by `180` ms
- limits results to `40`
- filters by node type
- filters by tags
- filters by minimum importance
- can restrict results to connected nodes only

## Weighted Scoring

Search weights:

| Field | Weight |
| --- | ---: |
| title | `12` |
| tags | `7` |
| type | `3` |
| description | `3` |
| relationships | `2.5` |
| metadata | `1.5` |

Additional bonuses:

- exact title match
- prefix title match
- importance
- recency

The result is a deterministic relevance score over in-memory graph data.

## Indexing

`src/lib/search` builds a local index from graph nodes and edges. It includes:

- normalized text fields
- tags
- node type
- relationship context
- metadata

There is no persistent external index and no vector store. Rebuilds happen locally when graph data changes.

## Highlighting

Matched text can be highlighted in result rows. Highlighting is derived from the same local query tokens used for scoring; it is not generated by a model.

## Command Palette

`Ctrl/Cmd+K` opens the command palette. It uses local fuzzy subsequence matching for commands and returns up to five quick node results. It is intended for navigation, not full-text research.

## Filters

- Node type: restrict to one of the defined node types.
- Tags: require selected tags.
- Minimum importance: exclude low-importance nodes.
- Connected only: exclude isolated nodes.

Filters apply before scoring or to the scored result set according to the panel implementation.

## Relationship Search

The relationship field contributes lower weight (`2.5`) so edges can improve relevance without overwhelming direct node text. Edge type and neighboring node text may contribute via relationship context.

## Local-Only Guarantees

- No query leaves the browser.
- No telemetry from search terms.
- No API keys, hosted search, or external search index.
- No embeddings or semantic model calls.

## Implementation Rules

- Keep scoring pure and deterministic in `src/lib/search`.
- Do not add network calls to search or command palette code.
- Preserve stable result ordering for equal scores.
- Keep the result limit at the panel boundary so algorithms remain reusable.
